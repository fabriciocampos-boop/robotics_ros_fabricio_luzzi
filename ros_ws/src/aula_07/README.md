# Aula 07 - Serviços

## Subtema

Implementação de serviços no ROS 2 utilizando o modelo cliente/servidor com requisições e respostas.

- **`custom_interfaces`:** Criar interfaces customizadas de serviço utilizando arquivos `.srv`, definindo os dados enviados na requisição e os dados retornados na resposta.

- **`mathematics_operations`:** Implementar em C++ um servidor e um cliente utilizando o serviço `AddTwoInts` para receber dois números inteiros, realizar a soma e retornar o resultado.

- **`physics_operations`:** Implementar em Python um servidor e um cliente utilizando o serviço `VectorDistance` para receber dois vetores, calcular a diferença entre eles e o módulo do vetor resultante.
