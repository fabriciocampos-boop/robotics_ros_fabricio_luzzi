# Aula 06 - Mensagens Customizadas

## Subtema

Criação e utilização de mensagens customizadas no ROS 2.

- **`robot_interfaces`:** Criar um pacote de interfaces utilizando `ament_cmake` e definir mensagens customizadas com arquivos `.msg`, incluindo tipos primitivos, mensagens compostas, arrays e `Header`.

- **`lista`:** Implementar e testar a comunicação utilizando as mensagens customizadas, criando publisher e subscriber para publicar e receber informações de obstáculos através de tópicos ROS 2.
